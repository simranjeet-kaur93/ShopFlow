# ShopFlow

**A production-minded e-commerce microservices platform built with NestJS and TypeScript.**

ShopFlow is a learning project focused on microservices architecture, distributed transactions, event-driven communication, security, and production readiness.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** NestJS, TypeScript
- **Communication:** REST, gRPC, RabbitMQ
- **Data:** PostgreSQL, Prisma, Redis
- **Infrastructure:** Docker, MinIO
- **Monitoring:** Prometheus, Grafana (planned)

## Project Status

**Current phase:** Phase 1 — Architecture and repository foundation

**Next:** Set up local infrastructure and scaffold the monorepo.

> Infrastructure and application functionality are planned, not yet implemented.
